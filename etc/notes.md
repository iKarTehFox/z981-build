# Just some tips
Hi, iKarTehFox here. After (or before) you install Z981, here's some info that might help you out.

### Camera
Yes, the camera **works**, unlike other custom ROMs. It functions just fine with the 13 MP camera on the Z981. Video technically works, but 1080p is a bit laggy. We have to disable the proprietary Qualcomm hardware encoder (It doesn't work...) so it falls back to software. 720p is smooth, though.

### Performance
The Z981 was never designed to run Android 9, but it runs smoothly enough. Go to `Developer options` and set all animation speeds to 0.5x to make it feel a bit snappier.

### Connectivity
I can only assume mobile data, calls, and messaging work fine, but I wouldn't count on it. It's an aging device and isn't fully supported by all modern carriers. My device, at least, was made for MetroPCS (now Metro by T-Mobile). If anything, place your bets on a T-Mobile SIM. At least on the stock ROM, messages came through with my Cricket Wireless SIM inserted, but calls outright failed (could've just been Android 6. I don't know if VoLTE is better supported, or rather *at all*, on LineageOS 16). The hardware (modem) stays the same; I don't think changing the Android version would make it work any better.
